# VLab4Mic

Welcome to CellPatcher!
This repository was initialised using LabConstrictor.
If you want to start using VLab4Mic, please go to the [How to Download and Install VLab4Mic?](#how-to-download-and-install-vlab4mic) below.
> If you are the developer of VLab4Mic, please customise this README file.

## How to Download and Install VLab4Mic?

The installer would only be available once VLab4Mic developer has created a release.
Please, go to [this page](.tools/docs/download_executable.md) and check if the installing instructions are there.
In case there is no documentation there, please [create an issue](https://github.com/HenriquesLab/LabConstrictor-VLab4Mic/issues) asking the developer to create a release.
## Documentation for VLab4Mic's Developers

Internal documentation on how to upload notebooks or create executables is available in the [.tools/docs](.tools/docs/README.md) folder.
